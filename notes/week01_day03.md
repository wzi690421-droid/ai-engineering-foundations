# Week 01 Day 03 学习复盘

## 完成内容

- 使用结构体表示日志和文件加载结果。
- 使用 `istringstream` 解析一行日志。
- 验证字段数量、状态码、等级和路径。
- 使用 `ifstream`、`getline` 逐行读取文件。
- 收集合法日志并统计非法行，处理文件打开失败。

## 核心理解

- `LogEntry& output` 是可修改引用，解析成功后函数需要通过它写回结果，因此不能加 `const`。
- 先写入临时变量 `parsed`，所有读取与验证成功后才赋给 `output`，避免失败时留下部分结果。
- `stream >> extra` 成功表示规定字段后仍有内容，应返回失败；读取失败且已到末尾，表示没有多余字段。
- `std::ifstream file(filePath)` 负责实际打开并读取文件；`result.opened` 只记录这次打开是否成功。
