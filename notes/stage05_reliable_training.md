# 阶段 05：可信训练与实验闭环

## 这一阶段解决了什么

模型“能训练”不等于实验可信。本阶段把 SmallCNN 升级为数据边界清晰、实验可追溯、能够严格续训、结果可解释并可冻结交付的工程。

## 数据边界

```text
CIFAR-10 官方训练部分 50,000
├→ 训练集 45,000：更新参数、估计 mean/std、使用数据增强
└→ 验证集  5,000：选择模型、调超参数，不更新参数

CIFAR-10 官方测试集 10,000
└→ 冻结全部决策后只做一次最终评估
```

`mean/std` 只能从训练子集估计。如果验证集参与统计，它的信息会进入训练预处理，形成数据泄漏。

验证集可以重复使用来比较方案，但使用次数越多，设计决策越可能逐渐针对该验证集。测试集不能用于挑模型；看完测试结果再改方案，相当于把测试集变成了验证集。

## 数据增强与指标解释

训练集使用随机裁剪和水平翻转；验证集使用原图的固定预处理。

增强后的训练图片更难，所以可能出现：

```text
训练准确率 < 验证准确率
训练损失   > 验证损失
```

这不一定是错误。还要考虑训练指标在整个 epoch 的参数更新过程中累计，而验证指标使用 epoch 结束后的最终参数。

A/B 对照结果：

```text
不增强：最佳验证准确率 68.70%
增强：  最佳验证准确率 71.18%
提升：  2.48 个百分点
```

数据增强会降低早期学习速度，但可能改善泛化并延缓验证损失恶化。

## 实验目录与记录

每次新实验使用独立 `run_时间戳` 目录，保存：

```text
config.json
results/history.csv
results/training_curves.png
checkpoints/latest_checkpoint.pt
checkpoints/best_model.pt
analysis/*
```

CSV 在训练开始前创建表头，每个 epoch 结束立即追加一行；这样中途退出也保留已有结果。

训练入口必须明确选择：

```bash
python train.py --new --augmentation on
python train.py --resume RUN_ID --augmentation on
```

裸运行不应偷偷创建新目录，否则用户容易误以为在续训。

## best、latest 与早停

- `best_model.pt`：验证指标历史最好时保存，用于最终推理。
- `latest_checkpoint.pt`：每轮保存最后状态，用于从中断点继续训练。

任意验证新高都应更新和保存 best；早停的 `min_delta` 只负责判断“提升是否足以重置耐心值”，不能阻止更高模型成为 best。

验证指标会波动，因此一次下降不应立即停止。早停的意义是减少已经长期无有效提升的训练时间，而不是保证找到理论最优点。

## 严格续训需要保存什么

只保存模型参数不能保证严格续训。需要恢复：

```text
模型状态
优化器状态
已完成 epoch
最佳指标与早停状态
DataLoader 生成器状态
Python / NumPy / PyTorch 随机状态
```

随机状态决定下一轮 shuffle、随机裁剪和翻转。如果没有恢复，模型可以继续训练，但不一定与不中断训练逐步一致。

严格实验结果：连续训练 2 轮与“训练 1 轮—保存—重启—再训练 1 轮”的每轮指标完全相同，最终参数最大差值为 `0.0`。

## 错误分析

混淆矩阵约定：

```text
行：真实类别
列：预测类别
```

某类别准确率的分母是该真实类别所在行的样本总数。高置信错误用于寻找“模型非常确信但仍判断错误”的模式，不能只看总准确率。

当前增强模型较难识别 `dog、bird、cat`，较好识别 `automobile、truck、ship`。

## 冻结与最终测试

最终模型由验证集选择：第 18 轮验证准确率 `71.18%`。冻结后记录文件 SHA-256，保证后续导出和部署使用的是同一份模型。

唯一一次官方测试结果：

```text
test accuracy：70.86%
test loss：    0.8345
```

测试结果与最佳验证准确率只差 0.32 个百分点，未发现明显的验证集过拟合。测试后不再修改当前模型方案。

## 常见误区

- 验证准确率比训练准确率高不等于数据泄漏；先检查增强和统计时机。
- 发现已经浪费训练时间时，早停无法收回过去成本；它只能减少后续浪费，并仍需保留历史 best。
- checkpoint 能恢复训练不等于严格可复现；必须验证中断前后轨迹是否一致。
- 混淆矩阵和曲线只是工具，必须说明它们如何支持结论。
