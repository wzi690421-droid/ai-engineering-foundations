# 阶段 04：CNN 与残差网络

## 这一阶段解决了什么

目标是从全连接网络过渡到真实图像模型，理解卷积、池化、BatchNorm 和残差连接，而不是只会调用 `Conv2d`。数据集使用 CIFAR-10。

## 卷积的核心关系

输入：

```text
[N,3,32,32]
```

卷积权重：

```text
[16,3,3,3]
```

含义是 16 个卷积核；每个卷积核都覆盖输入的 3 个颜色通道，并把三个通道的响应相加，最终产生一张特征图。因此输出是：

```text
[N,16,32,32]
```

不是 3 个通道分别产生 16 张、总共 48 张。颜色信息会被可学习权重组合，不是无规则互相干扰。

卷积适合图像的原因：

- 局部连接：先学习边缘、纹理等局部模式。
- 权重共享：同一卷积核在整张图上滑动，参数少且能识别不同位置的相同模式。
- 保留空间结构：不像 MLP 一开始就把像素完全展平。

## ReLU 与池化

- ReLU 把负值变为 0、正值保持不变，引入非线性，并保留形状。
- `MaxPool2d(2,2)` 在每个 `2×2` 区域保留最大值，使高宽减半、通道数不变。

SmallCNN 的形状链路：

```text
[N,3,32,32]
→ Conv/ReLU       [N,16,32,32]
→ MaxPool         [N,16,16,16]
→ Conv/ReLU       [N,32,16,16]
→ MaxPool         [N,32,8,8]
→ Flatten         [N,2048]
→ Linear          [N,10]
```

`Flatten(start_dim=1)` 保留 batch 维，只展开每张图片的特征。

## CNN 与 MLP 公平对照

对照实验要保证数据划分、顺序、初始化规则、优化器和训练轮数一致，并让参数量尽量接近，只改变模型结构。

结果：

```text
MLP：24,674 参数，5 轮验证准确率约 40.20%
CNN：25,578 参数，5 轮验证准确率约 65.64%
```

参数量接近但 CNN 明显更好，说明局部连接、共享权重和空间结构归纳偏置更适合图像。不能只说“CNN 没有展平”，真正原因是展平后 MLP 不再显式利用二维邻域关系。

## 残差连接

基本残差块：

```text
输入 x
├──────────── identity ────────────┐
└→ 卷积 → 激活 → 卷积 = F(x) ─────┤
                                   ↓
                              output=x+F(x)
```

网络学习的是对原特征的修正量 `F(x)`。如果某些层暂时没有学好，捷径仍提供直接的信息和梯度通道；它不是永远保留第一次的错误输出，每轮参数仍会根据损失更新。

逐元素相加要求形状完全相同。如果通道数、宽高或 stride 改变，就使用投影捷径：

```text
1×1 Conv + 合适的 stride
```

把 identity 对齐到与卷积分支相同的形状。判断条件不能只检查 stride，还要检查 `in_channels != out_channels`。

## BatchNorm 的训练与评估

- 训练模式：使用当前 batch 的均值和方差，并更新运行统计量。
- 评估模式：使用训练期间累计的固定运行统计量。
- 忘记 `model.eval()` 会让预测依赖当前推理 batch，尤其小 batch 时结果不稳定。

## 实验边界

SmallResNet 和 SmallCNN 同时在深度、通道、BatchNorm、池化和参数量上不同，因此直接比较结果不能把差异单独归因于“是否有残差”。严格验证残差作用时，其他结构应相同，只切换 shortcut。

## 已完成证据与薄弱点

- 卷积、ReLU、池化形状实验通过。
- SmallCNN、简单残差块、下采样残差块和 SmallResNet 前向运行通过。
- CNN/MLP 公平对照完成，阶段评分 `3.5/5`。
- 仍需巩固：卷积参数量与计算量、BatchNorm 统计维度，以及从零设计严格的残差消融实验。
