# Week 01 Day 01 学习复盘

## 1. `topKDistinct` 流程

通过只读引用接收 `vector<int>` 和 `k`，再复制数组，以免修改原数据。依次完成：

- `sort + greater`：降序排列。
- `unique + erase`：去除重复元素。
- 元素超过 `k` 时，`resize(k)` 截断。
- 返回最大的 `k` 个不同元素。

## 2. 为什么先排序再 `unique`

`unique` 只能处理相邻重复项。排序能让相同数字相邻；使用降序还能让最大元素排在前面。

## 3. 重复检测的复杂度

- 双重循环：时间复杂度最坏为 `O(n²)`，额外空间复杂度为 `O(1)`。
- 哈希集合：平均时间复杂度为 `O(n)`，额外空间复杂度为 `O(n)`。

很早发现重复时，双重循环可能更快；数据量较大或重复出现较晚时，哈希集合通常更好。

## 4. `find` 的正确判断

`find` 返回迭代器，不是元素值或下标；查找失败时返回 `end()`。正确判断是 `seen.find(value) != seen.end()`。

不能与 `0` 比较；测试碰巧通过也不代表语义正确。

## 5. 为什么不用 `size_t` 遍历元素值

`size_t` 是无符号类型，负数会转换成很大的正数。遍历 `vector<int>` 的元素值应使用 `for (int value : nums)`。

## 6. `reserve` 的取舍

- 插入元素很多时：减少扩容和重新哈希，通常能加速。
- 很早提前返回时：预留空间没有利用，反而增加时间和空间开销。
