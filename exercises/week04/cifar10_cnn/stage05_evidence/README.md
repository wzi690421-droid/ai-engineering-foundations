# 阶段 05：可信训练与实验闭环

## 本阶段解决的问题

本阶段没有继续追求更深的分类网络，而是把已有 SmallCNN 从“能够训练”升级为“数据边界正确、实验可追溯、结果可解释、能够严格续训并冻结交付”。

## 已完成内容

1. 数据边界
   - 固定把 CIFAR-10 官方训练部分成 45,000 张训练子集和 5,000 张验证子集。
   - 只使用训练子集下标估计 RGB 均值和标准差。
   - 训练集使用随机裁剪和水平翻转；验证集使用固定变换。
   - 官方 10,000 张测试集不参与训练、标准化、模型选择和超参数比较。

2. 实验记录
   - 使用统一配置保存 seed、batch size、学习率、划分大小、增强和早停参数。
   - 每个 epoch 追加原始 CSV，并生成训练/验证损失和准确率曲线。
   - `latest_checkpoint.pt` 用于中断续训，`best_model.pt` 用于最终推理。
   - 训练入口必须显式选择模式，防止裸运行意外创建新实验：

     ```bash
     # 开始新实验
     python train.py --new --augmentation on

     # 在原run目录续训
     python train.py --resume run_20260812_173948 --augmentation on
     ```

3. 数据增强 A/B
   - 不增强组最佳验证准确率：68.70%。
   - 增强组最佳验证准确率：71.18%。
   - 数据增强提高 2.48 个百分点，并延缓验证损失上升。

4. 模型选择和早停
   - 任意验证新高都会保存真正的最佳模型。
   - 早停使用独立参考值判断是否达到 `min_delta`，不会丢失小幅提高得到的最佳模型。
   - checkpoint 保存模型、优化器、DataLoader 生成器、全局随机状态和早停状态。

5. 结果解释
   - 保存全部验证预测、分类别准确率、混淆矩阵和高置信错误。
   - 增强组最难识别的类别是 dog、bird 和 cat，最好识别的是 automobile、truck 和 ship。

6. 严格续训复现
   - 对相同 256 张图片验证“连续训练 2 轮”和“训练 1 轮—保存—重启—恢复—再训练 1 轮”。
   - 每轮指标完全相同，模型参数逐项相同，最大参数差为 0.0。
   - 证据见 `resume_equivalence.json`。

7. 最终冻结与官方测试
   - 最终候选：`run_20260812_165446/checkpoints/best_model.pt`。
   - 选择依据仅为验证集准确率，最佳为第 18 轮的 71.18%。
   - 冻结模型 SHA-256：`24104a00192d26cf65a8d72397bc1d3b47f63f15fb0c1ccb16ebf80b631e89a1`。
   - 唯一一次官方测试准确率：70.86%；测试损失：0.8345。
   - 测试结果不得再用于修改模型或训练配置。
