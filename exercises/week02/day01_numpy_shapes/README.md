# Week 02 Day 01：NumPy 形状与线性层

## 今日目标

- 理解批量输入、权重、偏置和输出的形状关系。
- 不使用循环，实现线性层前向传播 `Y = XW + b`。
- 主动检查非法形状，并用测试证明广播行为正确。

## 形状约定

```text
X: (N, D)  N 个样本，每个样本 D 个特征
W: (D, H)  从 D 维输入映射到 H 维输出
b: (H,)    每个输出维度一个偏置
Y: (N, H)  N 个样本的 H 维输出
```

矩阵乘法只允许内部维度匹配：`X` 的第二维必须等于 `W` 的第一维。`b` 通过广播加到每一行。
